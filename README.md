## THE WORK — FEATURED PROJECTS

These repositories best represent the areas I've explored so far.

### 01 · WearTwin — Wearable Monitoring & Digital Twin Prototype

[![WearTwin](https://img.shields.io/badge/Explore-WearTwin-C9232D?style=flat-square&logo=github)](https://github.com/Sushantaman108Durgadas/WearTwin)

**ESP32 · PPG · IMU · Signal Processing · Python · Denoising Autoencoder**

An ongoing wearable-monitoring and Digital Twin prototype focused on physiological and functional-state monitoring.

Work in the repository includes:
- PPG data acquisition and preprocessing workflows.
- Stationary and motion-affected PPG recording analysis.
- Signal filtering, feature extraction and derived metrics.
- Exploration of a 1D convolutional denoising autoencoder.
- A software pipeline intended to support physiological-state analysis and a Digital Twin prototype.

*Status: Ongoing project. Sensor integration and system capabilities are being developed iteratively.*

### 02 · Smart Home Guard — Embedded Security System

[![Smart Home Guard](https://img.shields.io/badge/Explore-Smart%20Home%20Guard-C9232D?style=flat-square&logo=github)](https://github.com/Sushantaman108Durgadas/SmartHomeGuard_MPR2A)

**ESP32 · STM32 · Embedded C++ · FSM · UART · Firebase · Wokwi**

A Semester 5 mini-project that evolved from an ESP32 simulation into a multi-controller home-security prototype.

Work documented in the repository includes:
- Object-oriented embedded C++ design.
- Finite State Machine (FSM) logic for security states and transitions.
- Door monitoring using a magnetic reed switch.
- Motion detection using a PIR sensor.
- ESP32–STM32 communication over UART.
- Firebase telemetry and MIT App Inventor mobile-app integration.
- Wokwi simulation iterations for testing the embedded logic.

The project was developed collaboratively. The repository documents the team's evolution and implementation.

### 03 · Obstacle Detecting Gimbal — 2-Axis Spatial Scanning

[![Obstacle Detecting Gimbal](https://img.shields.io/badge/Explore-Obstacle%20Detecting%20Gimbal-C9232D?style=flat-square&logo=github)](https://github.com/Sushantaman108Durgadas/Obstacle_Detecting_Gimbal)

**ESP32 · Embedded C++ · Servo Control · Ultrasonic Sensing · Wokwi**

A two-axis servo gimbal that scans a configurable angular region using ultrasonic distance measurements.

Key implementation areas:
- Independent horizontal and vertical servo positioning.
- Configurable angular scanning limits.
- Distance measurement at scan positions.
- Spherical-to-Cartesian coordinate transformation.
- Modular, object-oriented C++ design.
- Wokwi simulation and a reproducible VS Code / Arduino CLI setup.

### 04 · Machine Learning From Scratch

[![ML From Scratch](https://img.shields.io/badge/Explore-ML%20From%20Scratch-C9232D?style=flat-square&logo=github)](https://github.com/Sushantaman108Durgadas/ml_from_scratch)

**C++ · GNU Octave · Neural Networks · SOFM · CNN**

An implementation-oriented exploration of machine-learning fundamentals, with an emphasis on understanding algorithmic operations rather than relying entirely on high-level frameworks.

The repository contains:
- **Supervised learning:** a feedforward neural network trained on the XOR problem.
- **Unsupervised learning:** a Self-Organizing Feature Map (SOFM), including Best Matching Unit selection and neighbourhood weight updates.
- **Deep learning:** a CNN experiment for classifying hand-coded 9×9 digit templates.

### 05 · Smart Dustbin — Intelligent Waste Monitoring

[![Smart Dustbin](https://img.shields.io/badge/Explore-Smart%20Dustbin-C9232D?style=flat-square&logo=github)](https://github.com/Sushantaman108Durgadas/Smart-Dustbin-Project-MPR1B)

**Embedded C/C++ · ESP32 · ESP8266 · Arduino · Blynk · ThingSpeak · Wokwi**

A collaborative mini-project repository documenting the evolution of a smart dustbin from basic automation to connected monitoring and more advanced simulated logic.

The repository contains multiple project iterations, including:
- Automatic lid operation and fill-level sensing.
- IoT connectivity and remote monitoring.
- Blynk and ThingSpeak integrations.
- Object-oriented simulation work.
- Radar-style scanning and area-based waste-level analysis.

*This is a forked/team project repository. The repository history and project versions should be read in that collaborative context.*
